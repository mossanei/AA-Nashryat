ساخت APK با GitHub (بدون نصب هیچ برنامه‌ای)

۱. در github.com یک حساب رایگان بسازید و وارد شوید.
۲. بالای صفحه روی + و بعد New repository بزنید. یک نام دلخواه (مثلاً aa-nashriyat) بدهید و Create repository را بزنید.
۳. در صفحه جدید روی «uploading an existing file» بزنید.
۴. این فایل ZIP را روی کامپیوتر از حالت فشرده خارج کنید. همه فایل‌ها و پوشه‌های داخلش (پوشه www، پوشه .github، فایل‌های package.json و capacitor.config.json) را با هم بکشید و در صفحه رها کنید. اگر پوشه .github دیده نشد، گزینه نمایش فایل‌های مخفی کامپیوتر را روشن کنید.
۵. پایین صفحه Commit changes را بزنید.
۶. به تب Actions بروید. ساخت خودکار شروع می‌شود (حدود ۵ تا ۱۰ دقیقه). اگر شروع نشد، Build APK را انتخاب و Run workflow را بزنید.
۷. بعد از سبز شدن، روی آخرین اجرا بزنید. پایین صفحه، بخش Artifacts، فایل aa-nashriyat-apk را دانلود کنید.
۸. فایل ZIP دانلودی را باز کنید. داخلش app-debug.apk است. آن را به گوشی بفرستید و نصب کنید (باید نصب از منبع ناشناس را در گوشی اجازه بدهید).
